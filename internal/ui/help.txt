*difi.txt*    difi — a calm, focused way to review diffs

==============================================================================
1. Introduction                                    *difi* *difi-introduction*
==============================================================================

difi is a terminal UI for reviewing Git and Mercurial diffs before you push.
It gives you a side-by-side file tree and diff view with syntax highlighting,
vim keybindings, and a color theme system.

Run difi in any repository:

    difi                  diff against HEAD
    difi main             diff against a named branch
    difi HEAD~3           diff against N commits ago
    git diff | difi       pipe raw diff from stdin

difi is open source and freely distributable under the MIT license.

==============================================================================
2. Navigation                                      *difi-navigation*
==============================================================================

The screen has two panes:

    Left pane             file tree of changed files
    Right pane            diff view for the selected file

> Moving Around

j / Down                 move cursor down one line
k / Up                   move cursor up one line
gg                       jump to the first line of the diff
G                        jump to the last line of the diff
:<number>                jump to line <number>
:$                       jump to the last line

> Scrolling

Ctrl-d                   scroll down half a page
Ctrl-u                   scroll up half a page
zz                       center the cursor line on screen
zt                       move cursor line to top of screen
zb                       move cursor line to bottom of screen

> Pane Focus

Tab                      toggle focus between tree and diff panes
h / Left                 focus the left pane (file tree)
l / Right                focus the right pane (diff)

==============================================================================
3. File Tree                                       *difi-file-tree*
==============================================================================

The left pane shows all changed files in a collapsible tree.

Enter                    on a directory — expand or collapse it
Enter                    on a file — same as pressing e (edit)
f                        toggle flat mode (show full paths, no tree)
j / k                    move selection up or down

In flat mode all files are shown as a single flat list with full paths.

==============================================================================
4. Editing                                         *difi-editing*
==============================================================================

e / Enter                open the selected file in your editor

difi opens the file at the exact line corresponding to the cursor position
in the diff. The editor is determined by, in order:

    1. DIFI_EDITOR environment variable
    2. EDITOR environment variable
    3. VISUAL environment variable
    4. vi (fallback)

Set a custom editor in ~/.config/difi/config.yaml:

    editor: "nvim"

==============================================================================
5. Visual Mode                                     *difi-visual-mode*
==============================================================================

Visual mode lets you select a range of lines in the diff.

V                        toggle visual selection mode
j / k                    extend the selection down or up
Esc                      exit visual mode

The selected range is highlighted with the cursor line background color.

==============================================================================
6. The Command Line                                *difi-command-line*
==============================================================================

Press : to open a vim-style command line at the bottom of the screen.

> Commands

:q, :quit                exit difi
:w, :write               refresh the diff view from disk
:help, :h                open this help buffer
:noh, :nohlsearch        clear visual selection highlight

:<number>                jump to line <number> in the diff
:$                       jump to the last line

:colorscheme <name>      switch the color theme
:theme <name>            alias for :colorscheme

:set <option>            change a setting live

> :set Options

:set number / nu          absolute line numbers
:set nonumber / nonu     hide line numbers
:set relativenumber / rnu relative line numbers
:set hybrid               hybrid mode (absolute on cursor line)
:set relative             relative mode
:set absolute             absolute mode
:set hidden               no line numbers

Press Tab to cycle through matching command names, theme names, and :set
option values. Press Esc to cancel the command line.

7. Color Themes                                    *difi-themes*
==============================================================================

difi ships with 17 built-in themes ported from popular vim colorschemes.
Set the default theme in ~/.config/difi/config.yaml:

    ui:

Or switch live with:

    :colorscheme <name>

8. Configuration                                   *difi-config*
==============================================================================

difi reads its configuration from ~/.config/difi/config.yaml.

> All Options

editor                 editor command (or env vars DIFI_EDITOR, EDITOR, VISUAL)
ui.theme               colorscheme name (see |difi-themes|)
ui.line_numbers        line number style (hybrid, relative, absolute, hidden)
ui.diff_add_bg         hex color override for added line backgrounds
ui.diff_del_bg         hex color override for deleted line backgrounds

> Example

    editor: "nvim"
    ui:
      line_numbers: "hybrid"
      theme: "nord"
